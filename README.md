# Clasificación de razas de perros y gatos con CNN y Transfer Learning

Proyecto final de visión por computador basado en el Oxford-IIIT Pet Dataset.

## Dataset

Este proyecto utiliza el Oxford-IIIT Pet Dataset, cargado mediante TensorFlow Datasets.

## Ejecución

Los notebooks fueron diseñados para ejecutarse directamente en Google Colab.
